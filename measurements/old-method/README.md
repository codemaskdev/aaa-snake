# Old method (frame rate method 1)

These are the measurements of v1.0, v1.1 and v1.2 made before 2026-10-14's prompt 4, kept as they were.
They took frame rate from the control screens of the first 60 s after navigation start. Since prompt 4,
frame rate is taken over the first 60 s of play (the same window as the JS heap), and v1.0 to v1.2 were
measured again with that method: see measurements/<version>.json. Why the method changed: DEVLOG.md.
